For participation you need a notebook with **MacOS, Windows or Linux** with **admin rights**.

If you don't have **admin rights** on your system please skip this installation and use the [StackBlitz in-Browser Editor](https://stackblitz.com/) instead that is linked via the ⚡️ in most of our tasks. If possible we recommend the installation on your system.

Please install the following tools:

**1. Install current version of Chrome (used for Angular developer tools)**

Download the installer here: <https://www.google.com/intl/en/chrome/browser/>

Install [Angular DevTools Chrome Extension](https://chrome.google.com/webstore/detail/angular-devtools/ienfalfjdbdpebioblfackkekamfmbnh)

**2. Install LTS version of Node.js  (the node package manager NPM will be installed as well) (Node.js  >= 20.x.x)**

Download the installer here: <http://nodejs.org/download/>

If you have to configure a proxy: <https://docs.npmjs.com/misc/config#https-proxy>


**3. Install angular-cli and demo backend api**

Install angular-cli with:

    $ npm install -g @angular/cli bookmonkey-api@5

**4. IDE / Editor**

You should install an IDE or a text editor with JavaScript support. We recommend WebStorm as commercial option (<https://www.jetbrains.com/webstorm/>) or Visual Studio Code (<https://code.visualstudio.com/>) as free option.

Regardless of the used editor, make sure you have installed the angular plugins / extensions to get full support of all features like auto completion and similar.

**5. Check your settings**

Please run the following commands in the terminal:

    $ node -v 
    $ npm -v
    $ npx ng version
